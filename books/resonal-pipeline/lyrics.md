---
title: "B-2. 作詞 — 表示用と Suno 用の2つを書く"
---

この章では、歌詞の作り方を説明します。作詞はAIが進める工程で、ワークフローとしてあなたの判断を待つ場所はありません。ただし、書き上がった歌詞をあなたが読んで、気になる点を伝えて直してもらえます。AIに「これで良いですか？」と聞かれたときは、そのまま答えてください。

## AIが書いて、自分で直す

AIは企画書を元に、歌詞を書きます。いきなり歌詞を書くのではなく、先に曲の場面を短い物語として書き、そこから削って歌詞にします。書き上げたあとは、読む視点を変えて自分で読み直し、直してから見せてくれます。

作詞の手順は、作詞について一般に語られてきた技法を僕なりに学び、AIへの指示に置き換えたものです。

## 気になったら、言葉で伝える

歌詞を読んで気になる所があれば、感じたままに伝えてください。RESONALのRerun Seasonでは、僕は次のように伝えました。

> おなじ、おんなじが冗長だと思った。シャレた表現できないかな

AIが数えると、「おなじ」「おんなじ」は曲全体で6回出ていました。そこで、「おなじ看板 おなじ雨 おなじ赤信号」を「看板も 雨も 赤信号も 台本どおり」のように、テレビや演劇の言葉に置き換えてもらいました。

こんな伝え方でも直してもらえます。

```
サビをもっと短く、言い切る感じに
2番のAメロが説明っぽい
「君」は使わないで
```

## 作風のこだわりは、セットアップで伝えておく

「この言葉は使わない」「サビに英語を少し入れたい」のような、毎回守ってほしいこだわりは、セットアップの「歌詞の言語と作風」の質問で伝えておくと、次の曲からAIが従います。あとから足したいときも、AIに頼めば設定に書いてくれます。

## 表示用とSuno用の2つを書く

歌詞は、2つの版で書かれます。1つはミュージックビデオ（MV）の字幕に使う、漢字かな交じりの表示用です。もう1つはSunoに貼るSuno用で、漢字をひらがなやカタカナに開いています。Sunoが漢字を読み間違えることがあるためです。

```text:Rerun Season（表示用）
交差点の大画面で 私が笑ってる
去年の顔のまま ずっと
```

```text:Rerun Season（Suno用）
こうさてんの だいがめんで わたしが わらってる
きょねんの かおのまま ずっと
```

2つの版は、行と内容をそろえて、読みだけを変えています。歌詞を直したいときは、表示用とSuno用の両方を直すようAIに頼んでください。

## 詳しく知りたいときは、AIに聞く

作詞の技法や、手順の中身が気になったら、作業しているAIに気軽に聞いてみてください。

```
この曲の歌詞を、どんな手順で書いたか教えて
作詞の skill で使っている技法を、初心者向けに説明して
```

## まとめ

作詞では、AIが物語を書いてから削って歌詞にし、自分で読み直して直します。気になる所は言葉で伝えれば直してもらえ、毎回守ってほしいこだわりはセットアップで伝えておけます。歌詞は、MVの字幕に使う表示用と、Sunoに貼るSuno用の2つが書かれます。
