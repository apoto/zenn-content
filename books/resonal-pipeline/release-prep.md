---
title: "B-6. リリース準備 — 素材と文面を揃える"
---

この章では、ミュージックビデオ（MV）にOKを出した後に、公開に使う素材と文面を揃える工程を説明します。AIが素材と文面を用意し、アップロードはあなたがチェックリストを見ながら手で行います。

## AIが揃えるもの

作るものは、セットアップで選んだリリース先で決まります。「リリースしない」を選んだ場合は、何も作りません。

| リリース先 | AIが揃えるもの |
|---|---|
| YouTube | タイトル・説明文・タグの文面、サムネイル |
| 配信サービス（Spotifyなど） | 曲名やジャンルなどの曲情報、3000×3000のジャケット |
| その他 | ジャケット |

どのリリース先でも、アップロードの手順を並べたチェックリストを作ります。説明文には、曲の紹介・クレジット・歌詞・使った生成AIが書かれます。

ジャケットはカバー画像から正方形に切り出すので、端が切れたり、細部が甘くなったりすることがあります。そのときは、AIが「このまま使う」か「正方形で描き直す」かを聞きます。

## 気になったら、言葉で伝える

文面は、AIが見せてくれます。気になる所があれば伝えてください。

```
説明文の冒頭を、もっと短く
タグに「シティポップ」を足して
```

## 名義とAI使用の申告は、規約を確かめる

作詞・作曲の名義をどう書くか、AIを使ったことをどう申告するかは、配信サービスやYouTubeの規約によって違い、変わることもあります。AIは書き方を断定せず、確かめるように伝えます。アップロードの前に、使うサービスの最新の規約を確認してください。

## アップロードはあなたが行う

アップロードと公開は、あなたが自分のアカウントで手で行います。AIはチェックリストを上から一緒に確かめ、どのファイルを使えばよいかを伝えて終わります。

## 詳しく知りたいときは、AIに聞く

作られたファイルの中身や、チェックリストの項目の意味は、AIに聞いてみてください。

```
release フォルダのファイルを、それぞれ説明して
YouTube にアップロードするときの手順を、もう少し詳しく教えて
```

## まとめ

リリース準備では、選んだリリース先の分だけ、AIが文面とジャケットなどの素材を揃えます。名義やAI使用の申告は、各サービスの規約を確かめてください。アップロードと公開は、あなたがチェックリストを見ながら自分のアカウントで行います。
