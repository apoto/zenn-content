この本は、公開しているワークフロー [resonal-workflow](https://github.com/apoto/resonal-workflow) のマニュアルです。最初から全部読む必要はありません。Claude Code か Codex にリポジトリを読み込ませれば、あとは AI との対話で進められます。このページには、始めるために最低限必要なことだけを書いています。

## できること

企画・作詞・作曲・マスタリング・ミュージックビデオ・リリース準備までの1曲の流れを、AI と一緒に進められます。AI が実作業を行い、案を選ぶ・音源を作る・MV を見て OK を出す・アップロードする、といった判断と仕上げを人が行います。

## 用意するもの

- macOS か Linux のパソコン
- [Claude Code](https://docs.anthropic.com/en/docs/claude-code) か [Codex](https://github.com/openai/codex)
- 音源を作るサービスのアカウント（推奨は Suno）

ffmpeg や Whisper などの道具は、セットアップのときに AI が確認し、足りなければ入れ方を案内します（入れる前に確認を取ります）。

## 始め方

Claude Code か Codex を開いて、次の1行を送ってください。

```
https://github.com/apoto/resonal-workflow をクローンしてセットアップして
```

すると、AI が次のことを1問ずつ聞いてきます。分からないものは「あとで決める」で先に進めます。

1. 作りたい音楽の傾向（ジャンル・ムード・テンポ感）
2. テーマ・世界観
3. 歌い手・キャラクター（立ち絵の画像があれば置き場所）
4. 歌詞の言語と作風のこだわり（任意）
5. ユニット名とクレジットの表記
6. 音の大きさ（配信の標準／音圧高め）
7. 使う外部サービス（推奨を示されるので、そのままでも、別のものに置き換えても構いません）

## 1曲作る

セットアップが終わったら、次のように話しかけます。

```
新曲を作りたい
```

あとは AI が工程を進め、人の番になると止まって、何をしてほしいかを伝えてくれます。

| 人の番 | やること |
|---|---|
| 企画 | AI が出した2〜3案から1つ選ぶ |
| 作曲 | AI が用意した文章を Suno などに貼って生成し、気に入った音源を置く |
| MV | できた動画を見て、OK か直してほしい点を伝える |
| リリース | 揃った素材と文面を使って、YouTube などにアップロードする |

## 困ったときに話しかけること

| こんなとき | 話しかける言葉 |
|---|---|
| いまどこまで進んだか知りたい | 「いまどこまで進んだ？」 |
| 前回の続きをやりたい | 「この曲の続きをやって」 |
| 設定を変えたい（キャラ・音楽の傾向など） | 「セットアップをやり直したい」 |
| 自分の歌や楽器を入れたい | 「歌は自分で歌いたい」 |

## もっと知りたいとき

各工程で何が起きているかは、それぞれの章で説明しています。気になったところだけ読んでください。

| 知りたいこと | 章 |
|---|---|
| 全体の流れ | 「全体像」 |
| セットアップで聞かれること・使うサービスの選び方 | 「はじめ方とセットアップ」 |
| 各工程の中身 | 企画〜リリース準備の各章 |
| 人が何をするか | 「人の仕事」 |
| このワークフローの元になった RESONAL の実際 | 「RESONAL の場合」 |
