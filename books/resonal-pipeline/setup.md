title: "A. セットアップ — はじめ方と、質問に答えること"
---

この章では、公開版のワークフローを使い始めるときの流れを説明します。

## Claude CodeかCodexに頼んで始める

使い始めるときは、Claude CodeかCodexを開いて、次のように頼みます。

```text
https://github.com/apoto/resonal-workflow
このリンク先のワークフローを使って、AI と一緒に曲を作りたいです。
手元に取り込んで、セットアップから始めてください。分からないことは質問してください。
```

するとAIがリポジトリを手元に取り込み、セットアップを始めます。最初に必要な道具が入っているかを確かめ、足りないものがあれば、入れ方を示して「入れてよいか」を1つずつ聞きます。了承する前に勝手に入れることはありません。

## 質問に答える

道具が揃ったら、AIが作りたい音楽について1問ずつ質問します。分からない項目は「あとで決める」で先に進めます。

| # | 聞かれること | 答えの例 |
|---|---|---|
| Q1 | 作りたい音楽の傾向 | 「夜の街のシティポップ、ゆったり」「ピアノのバラード」 |
| Q2 | テーマ・世界観 | 「都会の孤独と小さな救い」「放課後の青春」 |
| Q3 | 歌い手・キャラクターと、歌声のイメージ | 「キャラはいない」「若い女性の澄んだ声」 |
| Q4 | 歌詞の言語と作風のこだわり | 「日本語、サビに英語を少し」 |
| Q5 | ユニット名とクレジットの表記 | 「MOONLIT LANE」 |
| Q6 | 音の大きさ（`streaming` か `loud`） | 迷ったら `streaming` |
| Q7 | 使う外部サービス | 「Suno」「自分で用意する」「使わない」 |
| Q8 | どこにリリースするか | 「YouTubeだけ」「リリースしない」 |

キャラクターがいなくても、声だけの曲として作れます。立ち絵の画像があれば、カバー画像やミュージックビデオ（MV）で見た目を揃えるのに使われます。キャラクターがいる場合は、以降の会話でAIがそのキャラクターの口調で話すようになります。

答え終わると、AIが設定ファイルを書いて中身を見せてくれます。OKを出したら、セットアップは終わりです。次からは「新曲を作りたい」と話しかけると、企画から始まります。

## 使う外部サービスは選べる

音源・画像・動画素材・通知には、外部サービスを使います。推奨はありますが、ほかのサービスや手作業に置き換えられます。

![使うサービスは選べる](/images/resonal-pipeline/tools.png)
*推奨はあるけれど、セットアップで自分の使いたいものに置き換えられる*

| 用途 | 推奨 | ほかの選び方 |
|---|---|---|
| 音源 | Suno | 別のサービス／自分で作った音源を置く |
| 画像（カバー） | codex CLI | 別のツール／自分で用意する |
| 動画素材（MVの背景） | Kling MCP | 別のツール／使わない（背景は静止画） |
| 通知（できたMVを受け取る） | Slack | 使わない |

どのサービスも、生成はあなたが確認してから行い、失敗しても勝手に作り直しはしません。料金と利用条件はサービスごとに異なり、変わることもあります。使う前に、各サービスの料金ページと規約を確認してください。

## どんなジャンルにも使える

公開版には、RESONALのジャンルや彩瀬??の設定は入っていません。企画・作詞・作曲は、セットアップで答えた内容を読んで動くので、バラードでもアニソンでも同じ流れで作れます。記入例として、夜の街のシティポップを作る架空のユニットの設定を `profile.example/` に入れています。

設定はあとから変えられます。「セットアップをやり直したい」「画像生成を別のサービスにしたい」のように頼めば、AIがその項目だけ聞き直します。

## 詳しく知りたいときは、AIに聞く

設定ファイルの中身や、外部サービスの細かいつなぎ方は、AIに聞いてみてください。

```
セットアップで書かれたファイルを、それぞれ説明して
画像生成を自分の使っているツールにしたい。どう設定すればいい？
```

## まとめ

公開版のワークフローは、Claude CodeかCodexにリポジトリのURLを渡して、セットアップを頼むところから始まります。AIが1問ずつ質問し、答えをもとに設定ファイルを書きます。外部サービスは推奨を示したうえで、ほかのサービスや手作業にも置き換えられます。
