この本は、AI音楽ユニット **RESONAL** の1曲ができるまでのワークフローをまとめたものです。

RESONAL では、企画から作詞、作曲、マスタリング、ミュージックビデオ制作、リリースまでを、Claude Code と自作のスクリプトで進めています。僕が手を止めて判断するのは、そのうち3か所だけです。

先日、生成AIなんでも展示会 Vol.6 にこのワークフローを展示したところ、「動画はどうやって作っているのか」「マスタリングも自動なのか」といった質問を多くいただきました。しかし、その場では十分に答えられませんでした。そこで、あらためて文章にまとめることにしました。

## この本で分かること

- 1曲を企画からリリースまで進めるための、工程の全体像と人が判断する3か所
- 各工程で、どの Skill・スクリプトが何をして、どんな成果物ができているか
- ミュージックビデオ制作の細かい手順（歌詞のタイミング合わせ、Remotion での組み方、検査、レビュー）
- マスタリングの自動化（どの数値を目標にして、どう着地させているか）
- AI に長い自動処理を任せるときに気をつけている、「動いた」と「意図どおりになった」の違い

## 想定している読者

Claude Code や ChatGPT などの AI ツールを、すでに触っている方を想定しています。そのため、各ツールの基本的な使い方は説明しません。

一方で、音楽制作や動画制作の専門知識は前提にしていません。マスタリングや LUFS などの用語は、出てきたところで説明します。

## 読み方

前半（第1〜3章）で全体像を説明し、後半（第4章以降）で工程ごとに詳しく説明します。各章は単独でも読めるようにしているので、気になる工程から読んでいただいても大丈夫です。

コードは記事内に引用する形で載せています。RESONAL で使っているリポジトリ自体は非公開ですが、企画からミュージックビデオ完成までの部分を、誰でも使える形に切り出して公開しています。

https://github.com/apoto/resonal-workflow

この本は RESONAL の実際の環境（リリースや毎晩の監査まで含む）を説明しているので、公開しているリポジトリとは、スクリプトの場所や検査項目の数が違うところがあります。
