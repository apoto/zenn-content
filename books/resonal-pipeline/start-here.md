この本は、AIと一緒に曲を作るためのワークフロー（作業の手順をまとめたもの）のマニュアルです。最初から全部読む必要はありません。このページの「始め方」の節にあるプロンプトをAIに貼り付ければ、あとはAIとの会話で進められます。

## できること

曲の企画から、作詞・作曲・音の仕上げ（マスタリング）・ミュージックビデオ（MV）・公開の準備までを、AIと一緒に進められます。

作業の多くはAIが行います。人がやるのは、案を選ぶ・音源を作る・MVを見てOKを出す・YouTubeなどに公開する、といった判断と仕上げです。

## 用意するもの

- Macのパソコン（Linuxでも動きます）
- Claude CodeかCodex（AIがパソコンの中で作業をしてくれるアプリです。どちらか1つで大丈夫です）
  - [Claude Code](https://docs.anthropic.com/en/docs/claude-code)
  - [Codex](https://github.com/openai/codex)
- Sunoのアカウント（曲を生成するサービスです。ほかのサービスや、自分で作った音源も使えます）

ほかに必要な道具は、始めたあとにAIが確認して、足りなければ入れ方を案内してくれます（入れる前に確認を取ります）。

## 始め方

Claude CodeかCodexを開いて、次の文章をそのままコピーして貼り付け、送信してください。

```
https://github.com/apoto/resonal-workflow
このリンク先のワークフローを使って、AI と一緒に曲を作りたいです。
手元に取り込んで、セットアップから始めてください。分からないことは質問してください。
```

先頭のリンクが、このワークフローの置き場所です。AIがこのリンクを読み込んで、必要なものを手元に取り込み、準備を始めます。

## AIから質問されること

準備の途中で、AIが次のことを1つずつ質問してきます。分からないものは「あとで決める」と答えれば先に進めます。

1. 作りたい音楽の雰囲気（ジャンル・明るさ・テンポ）
2. 曲で表現したいテーマや世界観
3. 歌い手やキャラクターはいるか（イラストがあれば、その画像の場所）
4. 歌詞の言語や、こだわり（任意）
5. ユニット名と、動画に入れるクレジットの表記
6. 音の大きさ（配信の標準／迫力重視）
7. 使うサービス（おすすめが示されるので、そのままでも、別のものに変えても大丈夫です）

## 1曲作る

準備が終わったら、次のように話しかけてください。

```
新曲を作りたい
```

あとはAIが順番に作業を進めます。人の出番になるとAIは手を止めて、何をしてほしいかを教えてくれます。

| 人の出番 | やること |
|---|---|
| 企画 | AIが出した2〜3個の案から、1つ選ぶ |
| 作曲 | AIが用意した文章をSunoなどに貼って曲を生成し、気に入った音源をAIに渡す |
| MV | できた動画を見て、OKか、直してほしいところを伝える |
| 公開 | AIが揃えた画像や説明文を使って、YouTubeなどに公開する |

## 困ったときに話しかけること

| こんなとき | 話しかける言葉 |
|---|---|
| いまどこまで進んだか知りたい | 「いまどこまで進んだ？」 |
| 前回の続きをやりたい | 「この曲の続きをやって」 |
| 設定を変えたい（キャラや音楽の雰囲気など） | 「セットアップをやり直したい」 |
| 自分の歌や楽器を入れたい | 「歌は自分で歌いたい」 |

## もっと知りたいとき

それぞれの作業で何が起きているかは、各章で説明しています。気になったところだけ読んでください。

| 知りたいこと | 章 |
|---|---|
| 全体の流れ | 「全体像」 |
| 準備で聞かれること・使うサービスの選び方 | 「はじめ方とセットアップ」 |
| 各作業の中身 | 企画〜リリース準備の各章 |
| 人が何をするか | 「人の仕事」 |
| このワークフローの元になったRESONALの実際 | 「RESONALの場合」 |
