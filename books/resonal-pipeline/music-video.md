---
title: "MV — テンプレートを出発点に、自由に作り変える"
---

この章では、MVの作り方を説明します。公開版にはMVのテンプレートが入っていて、まずはそれで1本作れます。ただ、伝えたいのはテンプレートの中身よりも、それを自分の好きな形に作り変えるときの考え方です。こうしたいことを言葉で伝え、AIが18の軸と演出の辞書に置き換える、というやり方は、どんな映像を作るときにも使い回せます。

## まずはテンプレートで1本作る

MVはRemotionで作っています。Remotionは、Reactのコンポーネントとして書いた画面を、1フレームずつ描いて動画にするライブラリです。画面がコードなので、AIがコードを書き換えるだけで動画を直せます。

![](/images/resonal-pipeline/remotion-code.jpg)
*RESONALのMVの画面。左がコード、右がRemotion Studioのプレビュー。*

MVの工程では、AIが次のコマンドを1回実行します。

```bash
./tools/make_mv.sh "songs/<曲フォルダ>"
```

![make_mv.shの中の流れ](/images/resonal-pipeline/mv-pipeline.png)
*make_mv.shの中で走る工程。番号の順に実行する。*

| # | やること |
|---|---|
| 01 | Whisperで歌を文字起こしし、語ごとの秒を取る |
| 02 | 実際の音源からテンポと音の強さを測る |
| 03 | 背景と前景（立ち絵か、カバー画像からの切り抜き）を用意する。背景のループ動画があれば使う |
| 04 | `LYRICS.md` の文言を、Whisperの秒に合わせて並べる |
| 05 | 本編・ショート・サムネイルを書き出す |
| 06 | 書き出した動画が壊れていないか、クレジットが入っているかを確かめる |

歌詞の文言にWhisperの聞き取り結果を使わないのは、空耳が混じるためです。文字の大きさは行の長さから自動で決まり、画面からはみ出しません。カメラの動きやショートの区間も、8小節ごとの音の強さから自動で決めます。そのため、何も書かなくても1本できあがります。

## テンプレートは出発点

できあがったMVは、あくまで出発点です。テンプレートは、役割ごとにファイルを分けています。

| 変えたいもの | 書き換える場所 |
|---|---|
| カメラの動き・演出を入れる秒・ショートの区間 | `input/song.config.ts`（振り付け） |
| 書体・配色・字幕・装飾 | `src/styles/`（見た目の型） |
| カメラ・合成・クレジットの仕組み | `src/engine/` |
| タイトル・クレジットの文言 | `workflow.config.json` |

ただ、どのファイルをどう書き換えるかを、利用者が覚える必要はありません。「サビでカメラをもっと寄せたい」「文字を明朝にしたい」と伝えれば、AIが該当する場所を書き換えて、`make_mv.sh` で作り直します。

## 作り変えるときは、言葉で伝える。AIが軸と演出の辞書に置き換える

「もっとかっこよく」と伝えても、AIは何を変えればよいか分かりません。そこで公開版には、見せ方を具体的にするための道具を2つ入れています。「どこを決めるか」を分けた18の軸と、「どう見せるか」の選択肢を集めた演出の辞書です。

**18の軸**は、MVで決める項目の一覧です。18通りの見せ方があるという意味ではありません。

| 分類 | 軸 | 選択肢の例 |
|---|---|---|
| 歌詞（6） | 重ね方・配置・書体・出入り・装飾・帯 | 配置：中央／下帯／左右の端に縦書き。書体：極太ゴシック／明朝／丸ポップ |
| キャラクター（6） | 出すか・素材・動き・構図・前景の分離・表情 | 動き：呼吸だけ／拍に合わせて跳ねる／関節で動かす |
| 背景（4） | 素材・切り替え・画面エフェクト・カメラ | カメラ：ゆっくり移動／押し込み／周回／ホイップパン |
| 打点（2） | どこで入れるか・どう抜くか | サビだけ／全編。暗転／光ワイプ／ネガ反転 |

**演出の辞書**は、各軸に入れる選択肢の中身です。演出73件と場面19件の、合わせて92件が入っています。演出は、カメラ・編集・光と色・エフェクト・文字・構図・動き・UIの8つの分類に分けています。場面は、水中・雨の街・駅のホームのような場所ごとに、光と演出の組み合わせをまとめたものです。1件ごとに、何が起きるか、合う感情とタイミング、作るときの数値、相性のよい演出と悪い演出、できあがりの確認項目を書いています。公開版の `direction-library/` に入れています。

ただ、人が18の軸や92件の辞書を覚えて、選んで伝える必要はありません。人は、気になったことや、こうしたいことを言葉で伝えます。AIがそれを軸の値と辞書の演出に置き換えて、区間ごとの演出表（`DIRECTION.md`）に書き、テンプレートを書き換えます。辞書を引くのは主にAIです。

たとえばDive Reflexで、僕はこう伝えていました。辞書のことは意識していません。

| 僕が伝えたこと | AIが決めた軸の値 | AIが使った辞書 |
|---|---|---|
| 「水面と水中の切り替えは難しいと思うから、その瞬間は無理にとらなくていいよ」 | 打点の抜き方＝光ワイプ。着水・潜水・浮上の瞬間は撮らず、カットと光でつなぐ | `light-flood-wipe`（光で画面を洗って切り替える）・`crash-zoom`（浮上の急な寄り） |
| 「彩瀬主観で泳いでる映像も撮れるかな？」 | 背景のカメラ＝間奏だけ主観で泳ぐ | `pov-shot`（主観ショット）・`orbit`（周回） |
| 「ダンスはそもそも不要にしよう。せっかく綺麗な世界観だから壊したくない」 | キャラクターの動き＝静かな芝居（座って足をぶらぶら・胸に手を当てる・砂粒をかざす） | `breathing-idle`（呼吸だけの静止） |
| 「野球の音とか歌詞に出てくるってことは、わりと川とかの歌なのかなーってイメージした」 | 背景の素材＝対岸が近い入り江（護岸・電柱・家の灯り）。ラジオの寄りを足す | 場面 `beach-sunset`（夕暮れの水辺） |

僕が何も言っていない軸は、AIが曲と画から決めて、理由を添えて書きます。たとえば歌詞は、画面の中央が水面の境界とキャラクターの居場所なので下帯に退け、リアルな風景の上で浮かないように細い明朝の白にしました。Dive Reflexでは、こうして区間ごとに演出24件と場面2件を辞書から使っています。既定のままにする軸も「既定」と書いておくと、決めていないのか、既定を選んだのかを区別できます。

この作り方は、どんな映像でも使い回せます。音ゲー曲でもバラードでも、キャラクターがいてもいなくても、決める項目は同じ18の軸です。最初のMVができたあと、AIは「ここから軸と演出の辞書で作り変えられます」と案内します。辞書を自分で眺めて選びたい場合は、「MVの見せ方を選びたい」と話しかけると、skill `mv-styles` で軸を1つずつ一緒に決めていきます。

## RESONALの13のスタイルを使う・作り変える

RESONALでは、よく使う軸の組み合わせに名前を付けて「スタイル」と呼んでいます。「白い図形と極太ゴシックの白黒反転」「3Dの世界をカメラで飛ぶ」などで、2026年10月時点で13あります。

![Dive Reflex（gothic3d）。夕方の桟橋から潜り、底に仰向けになって、夜の水面に浮かんでくる](/images/resonal-pipeline/style-dive-reflex.jpg)
*Dive Reflex（gothic3d）。夕方の桟橋から潜り、底に仰向けになって、夜の水面に浮かんでくる*

13のスタイルと既定の型の見た目は、次の「スタイル図鑑」の章に画像つきで並べています。

この13のスタイルの実装も、公開版の `styles/` に入れています。発展途上のまま共有しているので、スタイルごとに手順や作りは揃っていませんが、そのまま使ってもらって構いません。

使っていて物足りなくなったら、自分の表現を足せます。新しいスタイルを `styles/` に作る、既存のスタイルを改変する、演出の辞書に新しい演出を1件足す、といったことを、同じ軸と辞書の型に合わせて進められます。もちろん、ワークフロー自体を作り変えて、まったく新しい形にしても構いません。

## 人が見て、直す

レンダーと検査が通ると、AIは本編・ショート・サムネイルを並べて、「見て、OKか、直したい点を教えてください」と頼んで止まります。ここは人の番です。

直したい点を伝えると、AIは直し方を2〜3案示し、選んだ案で書き換えて作り直します。往復は何度でもかまいません。OKが出たら、AIが `song.json` の `approved_at` に日付を入れ、MVの工程が終わります。

### 気に入らないところは、遠慮なく指示する

テンプレートの初稿には、気に入らないところが必ず残ります。人が指示を出せば直せるので、気になったところは遠慮なく伝えてください。伝えるときは「この曲だけか、次の曲からもか」を添えると、AIが直す場所を選べます。言わなかった場合は、AIが聞き返します。

**この曲だけ直す**　曲のプロジェクトの設定を書き換えます。次の曲には影響しません。

```
2分29秒あたりで、絵の主役が画面の外に出てしまう。主役が映るように寄せて
この曲だけ、サビの頭の白飛びを弱めて
歌詞の文字をもう一回り大きくして
```

**次の曲からも同じにする**　テンプレートかスタイルのほうを直します。作り終えた曲には届かないので、今の曲にも同じ直しを入れます。

```
右上の計器のような表示は、次の曲からも出さないようにテンプレートを直して
サビの頭の白飛びは、次の曲からもずっと弱めにして
```

**新しい見せ方として残す**　今回作り変えた見せ方に名前を付けて、スタイルとして残します。

```
今回の見せ方を、新しいスタイルとして styles/ に足して
```

アーティスト名やクレジットの文言、音の大きさのような設定の値は、`workflow.config.json` を直します。「セットアップをやり直したい」と伝えれば、その項目だけ聞き直されます。

## まとめ

MVは、テンプレートで1本作ったあと、自由に作り変えていく工程です。作り変えるときは、こうしたいことを言葉で伝えると、AIが18の軸と演出の辞書に置き換えて書き換えます。RESONALの13のスタイルはそのまま使えて、物足りなくなったら同じ型で新しく作ったり改変したりできます。
