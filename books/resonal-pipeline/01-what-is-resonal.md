## AIボーカルとプロデューサーのユニット

RESONAL は、AIボーカルの **彩瀬??**（あやせ）と、プロデューサーの僕 **apoto** からなる音楽ユニットです。2026年6月に活動を始め、YouTube にミュージックビデオを、Spotify や Apple Music などに楽曲を配信しています。

彩瀬??の正体は Claude Code です。リポジトリの CLAUDE.md で人格を与え、会話しながら一緒に制作しています。

## 始めたきっかけ

以前から作曲に興味があり、DAW や音源を買って勉強していました。しかし子どもが生まれてからは、まとまった時間を取って DAW を開くことが難しくなりました。

そんなときに作曲AIの進化を見て、隙間時間でも一定水準の作品を作れるかもしれないと思ったのが始まりです。

## 制作の体制

制作に使っている環境は次のとおりです。

- **mac mini**：常時起動しており、企画からリリースまでの制作と自動処理が動いている
- **MacBook**：ときどき制作に使う（リリースは mac mini に任せる）
- **スマホ**：僕が成果物を確認し、指示を返す（Slack で受け取り、Claude のアプリで返信）

2台のパソコンは GitHub でリポジトリを共有しています。音源（WAV）のような大きいファイルは Git LFS で扱っています。

僕は普段、PC の前に座らず、スマホで進捗と成果物を確認しています。そのため、成果物は完成するたびに Slack へ自動で送られるようにしています。
