この章では、公開版のワークフロー（resonal-workflow）で1曲を作るときの全体像を説明します。

## 2つの段階

ワークフローは、大きく2つの段階に分かれています。

- A. セットアップ：リポジトリを手元に置いた直後に1回だけ行います。AIが作りたい音楽や歌い手について質問し、答えを設定ファイルに書きます
- B. 曲作成：「新曲を作りたい」と話しかけるたびに始まります。企画からリリース準備までの6つの工程を、AIとあなたが交互に進めます

2曲目からは、「新曲を作りたい」と話しかけるところから始められます。

## B. 曲作成の6つの工程

| # | 工程 | AIがやること | あなたがやること |
|---|---|---|---|
| B-1 | 企画 | 曲の案を2〜3本出す | **案を選ぶ** |
| B-2 | 作詞 | 歌詞を書いて、直す | （読んで直しを頼める） |
| B-3 | 作曲 | 音源の生成に貼る文章と、カバー画像を用意する | **Sunoなどで音源を生成して置く** |
| B-4 | マスタリング | 音量を配信向けに整える | （気になる所を伝えられる） |
| B-5 | MV | 歌詞が出るミュージックビデオを作る | **見て、OKか直したい点を伝える** |
| B-6 | リリース準備 | 説明文やジャケットなど、公開に使うものを揃える | **アップロードする** |

## あなたが判断する場所は4つ

このワークフローが作業を止めて、あなたの判断を待つ場所は、表の太字にした4つです。

1. 案を選ぶ：AIが出した企画案から1つを選びます。混ぜたい点や変えたい点があれば、それも伝えます
2. 音源を作る：AIが用意した文章をSunoなどに貼って生成し、気に入ったものを置きます
3. MVを見る：OKを出すか、直したい点を伝えます。直しは何度でも頼めます
4. アップロードする：チェックリストを見ながら、YouTubeなどに上げます

この4つでは、AIは何をしてほしいかを具体的に伝えて止まります。

ただ、AIの進め方は毎回少しずつ違うので、この4つ以外でも「これで良いですか？」と聞かれることがあります。たとえば、歌詞を書き終えたところで確認を求められる場合です。そのときは、そのまま答えてください。どの工程でも、気になったことを伝えれば直してくれます。

## 途中でやめても、続きから再開できる

1曲の制作が数日に分かれても大丈夫です。次の工程はAIが曲のフォルダの中身から判断するので、あなたが順番を覚えておく必要はありません。再開するときは、次のように話しかけます。

```
いまどこまで進んだ？
この曲の続きをやって
```

企画書・歌詞・音源・MVなどの成果物は、曲ごとのフォルダ（`songs/<日付>_<曲名>/`）に揃っていきます。Claude CodeとCodexのどちらで進めても、同じように動きます。

## 詳しく知りたいときは、AIに聞く

工程の進め方の仕組みや、各ファイルの中身は、この本では細かく説明しません。知りたくなったら、作業しているAIに聞いてください。

```
./next.sh が何をしているか教えて
曲のフォルダにあるファイルを、それぞれ説明して
```

## まとめ

公開版のワークフローは、最初に1回だけ行うセットアップと、企画・作詞・作曲・マスタリング・MV・リリース準備の6つの工程でできています。あなたが判断する場所は、案を選ぶ・音源を作る・MVを見る・アップロードする、の4つです。途中でやめても、AIに聞けば続きから再開できます。
