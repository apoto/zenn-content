ここまで読んでいただき、ありがとうございました。

この本では、RESONAL の制作環境を誰でも使える形に整えた公開版のワークフローを、セットアップから6つの工程まで説明しました。振り返ると、ワークフローの中心にあるのは次の3つだと思います。

- **次にやることを機械が返す**：`next.sh` が曲フォルダの中身を見て1件だけ返すので、人も AI も順番を覚えなくてよい
- **完了を機械が判定する**：工程が終わったかを、ファイルがあるかだけでなく、音量や画像のサイズなどの中身を測って判定する
- **人は判断と言葉に集中する**：案を選ぶ、音源を生成する、MV を見る、アップロードする、の4つが人の番で、足りないものには名前をつけて伝える

AI が初稿を作り、人が確認して判断し、指示を出して良くしていく。AI は実作業を行うツールで、制作はあくまで人間のクリエイティブの延長だと考えています。

## 試してみたい方へ

公開版のワークフローは GitHub に置いています。Claude Code か Codex を開いて、次のように URL を貼って頼むだけで始められます。

```
https://github.com/apoto/resonal-workflow をクローンしてセットアップして
```

あとは対話で、作りたい音楽の傾向や世界観、キャラクター、使うサービスを聞かれます。セットアップが終わったら「新曲を作りたい」と話しかけると、1曲目が始まります。

https://github.com/apoto/resonal-workflow
