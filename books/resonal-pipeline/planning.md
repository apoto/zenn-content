---
title: "B-1. 企画 — 2〜3案から1つ選ぶ"
---

この章では、新曲の企画の進め方を説明します。企画は6つの工程の1つ目で、あなたが判断する場所の1つ目でもあります。

## 流れ

1. 「新曲を作りたい」と話しかける
2. AIが「今回やってみたいことはあるか」を1問だけ聞く
3. AIが案を2〜3本出して止まる
4. あなたが1つ選ぶ
5. AIが企画書（`BRIEF.md`）を書く

## 1問だけ聞いてから案を出す

案を出す前に、AIは次の1問だけを聞きます。

> 今回やってみたいことはありますか（テーマ・曲調・歌詞の言語・いつもと違う挑戦など）。無ければ『おまかせ』でOK

特にやりたいことが無ければ「おまかせ」で進められます。答えをもらったら、AIはセットアップで答えた音楽の傾向や世界観を読み、案を2〜3本出します。各案には、仮タイトル・一言でどんな曲か・ジャンルとテンポ・歌詞の切り口が並びます。

案は、これまでに作った曲と似すぎないように出されます。作った曲の一覧は、AIが自動で記録しています。

## 案はあなたが選ぶ

AIは案を1本に絞らず、並べて「どれにしますか」と聞いて止まります。1案だけだと良いか悪いかしか言えませんが、2〜3案あると比べて選べるためです。AIが自分で1つを選んで先に進むことはありません。

選ぶときは、案をそのまま選ぶだけでなく、注文を足せます。

```
Bにする。でもテンポはAくらいゆったりで
AとCを混ぜて。タイトルはCのほうがいい
どれもピンとこない。もっと明るい案を出して
```

選んだ案は、企画書 `BRIEF.md` にまとめられます。後の作詞・作曲・ミュージックビデオ（MV）は、この企画書を元に進みます。選ばなかった案も、候補として企画書に残ります。

## 詳しく知りたいときは、AIに聞く

企画書の書き方や、案の出し方の決まりが気になったら、作業しているAIに気軽に聞いてみてください。

```
BRIEF.md の各項目が何に使われるか教えて
案を出すとき、どんな決まりで出している？
```

## まとめ

企画では、AIが1問だけ聞いてから案を2〜3本出し、あなたがその中から1つを選びます。選ぶときは注文を足したり、案を混ぜたりできます。選んだ案は企画書にまとめられ、後の工程の元になります。
